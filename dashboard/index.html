Method & Experimental Setup

Overview of prompt generation, refusal representation extraction, activation gating, and evaluation protocol.

1

Prompt Variants

Every harmful and harmless query is tested across four parallel variants: English source (en), Kannada native script (kn), Latin transliteration (kn_latn, Kanglish), and code-mixed (kn_mix).

2

Direction Extraction

Contrastive refusal vectors r = E[h_harmful] - E[h_harmless] are extracted from middle representations using English-only direction pairs, avoiding any Kannada data contamination during representation capture.

3

Gated Steering

Unlike constant steering which over-refuses harmless queries, gated steering projects the layer activation onto r and only applies the steering vector +alpha * r if activation exceeds threshold tau.

4

Baseline Comparison

Benchmarked against an external moderation pipeline: IndicTrans2 machine translation to English followed by Llama Guard 3 1B moderation classification.
