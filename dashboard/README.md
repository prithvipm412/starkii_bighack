# Bhasha Kavach — Results Dashboard

**Single-page static dashboard** for the Bhasha Kavach safety-gap study.
No backend required. Opens from the filesystem or any static file server.

## Quick start

```bash
# Option 1 — npx serve (zero install)
npx serve dashboard

# Option 2 — Python built-in
python3 -m http.server 8080 --directory dashboard

# Option 3 — Vite (if you prefer hot-reload)
# cd dashboard && npx vite
```

Then open <http://localhost:3000> (or whatever port is shown).

## Sample data

`dashboard/sample/results_sample.csv` — **⚠️ SAMPLE DATA, not real results.**
Generated by `dashboard/sample/generate_sample.py` (seed=42, 15 360 rows).
Schema: `prompt_id, split, category, variant, model, condition, refused, judge_score, latency_ms, commit`

## Switching to real pilot CSVs

1. Place pilot output CSVs (same schema) in `results/mac1/`, `results/mac2/`, etc.  
   Name them `results.csv`, `output.csv`, `eval.csv`, `pilot.csv`, or `full.csv`.
2. Click **Full (real CSVs)** in the dashboard header toggle.

## Views

| # | Name | What it shows |
|---|------|---------------|
| 1 | The Gap | Harmful-prompt refusal rate by variant, grouped by model (condition=none) |
| 2 | The Fix | Harmful refusal rate vs wrong-refusal on harmless, per condition |
| 3 | Cost | Median latency per condition |
| 4 | Where it fails | Category × variant cells where steer_gated has the lowest refusal rate |
