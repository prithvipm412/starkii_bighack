# Bhasha Kavach — Results Dashboard

**Single-page static dashboard** for the Bhasha Kavach safety-gap study.
No backend required. Opens from the filesystem or any static file server.

## Quick start

```bash
# Option 1 — npx serve (zero install)
npx serve dashboard

# Option 2 — Python built-in
python3 -m http.server 8080 --directory dashboard

# Option 3 — Vite (if you prefer hot-reload)
# cd dashboard && npx vite
```

Then open <http://localhost:3000> (or whatever port is shown).

## Sample data

## Switching to real pilot CSVs

1. Place pilot output CSVs in `results/mac1/`, `results/mac2/`, etc.  
   Name them `<model>_<condition>.csv` per AGENTS.md (e.g. `gemma-2-2b-it_none.csv`).  
   Header **must** be exactly: `prompt_id,split,category,variant,model,condition,refused,judge_score,latency_ms,commit`  
   CSVs with any other header (e.g. `handlabels.csv`, `translation_check.csv`, `sweep_*.csv`) are silently skipped.
2. Click **Full (real CSVs)** in the dashboard header toggle.
