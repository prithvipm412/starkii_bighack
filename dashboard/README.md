# Bhasha Kavach — Results Dashboard

## Open it

```bash
npx serve dashboard
```

Then open the URL shown (default <http://localhost:3000>).

Alternatives if `npx serve` is unavailable:

```bash
python3 -m http.server 8080 --directory dashboard
# → http://localhost:8080
```

---

## What it shows

| View | Name | Description |
|------|------|-------------|
| 1 | The Gap | Harmful-prompt refusal rate by variant × model, `condition=none`. Lower bars = safety gap. |
| 2 | The Fix | Harmful refusal rate (↑) vs wrong-refusal on harmless (↓), per condition. |
| 3 | Cost | Median latency per condition. |
| 4 | Where it fails | Category × variant cells where `steer_gated` still has the lowest refusal rate. |

Header strip: project name, hypothesis, **Pilot (sample) / Full (real CSVs)** toggle,
orange **SAMPLE DATA** badge (visible only when sample data is active).

Status bar (below header): per-model row counts + last-updated time — watch this
update as runs land in `results/mac*/`.

## Switching to real pilot CSVs

1. Place pilot output CSVs in `results/mac1/`, `results/mac2/`, `results/mac3/`, `results/mac4/`.  
   Name them `<model>_<condition>.csv` per AGENTS.md  
   (e.g. `qwen2.5-3b-instruct_none.csv`, `gemma-2-2b-it_steer_gated.csv`).

2. Required header (exactly, no extra spaces):
   ```
   prompt_id,split,category,variant,model,condition,refused,judge_score,latency_ms,commit
   ```
   CSVs with any other header (`handlabels.csv`, `translation_check.csv`, `sweep_*.csv`, …)
   are **silently skipped** — no errors.

3. Click **Full (real CSVs)** in the dashboard header.  
   The **SAMPLE DATA** badge disappears automatically.
